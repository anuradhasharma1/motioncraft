# MotionCraft

An interactive scrollytelling experience that explores the principles of modern CSS animation, motion design, and GPU-accelerated performance through immersive visual experiments.

## ✨ Features

- Smooth cinematic scrolling
- Interactive easing curve visualizer
- Geometric transform playground
- GPU vs CPU animation comparison
- Real-time CSS animation generator
- Responsive monochrome UI
- Framer Motion powered interactions
- Performance-focused animation design

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis
- Vercel
